# ToDo List

Веб-додаток для керування списком завдань.

## Функціонал

- Додавання завдань
- Позначення завдань як виконаних
- Видалення завдань
- Збереження даних на сервері у файлі tasks.json

## Технології

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## Встановлення

Клонувати репозиторій:

```bash
git clone https://github.com/Makarenko-Ant/AI_project_toDo_List
```

Перейти до папки проєкту:

```bash
cd AI_project_toDo_List
```

Встановити залежності:

```bash
npm install
```

Запустити сервер:

```bash
node server.js
```

Відкрити у браузері:

```text
http://localhost:3000
```
